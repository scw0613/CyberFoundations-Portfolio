## In My Own Words

**What's the difference between a file and a folder, and how do they form a tree together?**

```
A file is a small component, and a folder is a collection of files saved together for organization purposes. Just as a collection of files can be organized into a folder to create a branch, then a collection of folders can be further organized to make a different branch. The branches are held together by the base of the tree and grow from it into smaller branches.
```

**How does a Windows-style file path differ from a Linux-style file path?**

```
A Windows-style path has 2 main differences: first, the drive folder is listed in the path name, but one isn't listed in a Linux-style path. Second, the backslash (\) is used in a Windows-style path, but the forward slash (/) is used in a Linux-style path.
```
